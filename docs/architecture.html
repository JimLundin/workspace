Workspace architecture: libraries declare shapes, entry points supply the values

Each program's __main__ (and launch.py) builds every chosen value from the data packages and hands it in; keyboard/ and desktop_ui/ declare types and behaviour only, and tests hand them their own values. Click any box to zoom in, then open a file to read its code.
